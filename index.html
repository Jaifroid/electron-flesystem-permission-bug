File System Access API Persistent Permissions Test

This test demonstrates persistent filesystem permissions working in Electron nightly (requires PR #48170). Also works in Chromium-based browsers (Chrome, Edge).

Writable:

For Electron testing: Install nightly with npm install electron-nightly and update package.json start script to "start": "npx electron-nightly ."

  1. Hit the button to choose a directory. It must not be a 'special' directory, such as your documents or downloads folder. Make a new folder if in doubt.
  2. You should see your directory name, and it should say 'granted' in green for writable status.
  3. Now, close the app and run it again. Your directory should still be there, and it should still say 'granted' if the test has passed and persistent permissions have been granted by the user.
  4. If it says 'prompt' with a security error in red informing you that user activation is required (a click, for example), then persistent permission has not been granted.
  5. If this happens in Browser context, then try picking the folder again, until the Browser prompts you to grant persistent permissions (may need two tries, restarting the app in-between). Ensure you select 'Always' when prompted for persistent permissions.
  6. In Electron nightly (40.x+), persistent permissions now work correctly when both setPermissionRequestHandler() and setPermissionCheckHandler() are implemented in the main process. See main.js for the complete implementation.
Developer Setup Instructions for Electron Nightly (expand for details)
  1. Install Electron nightly: npm install electron-nightly
  2. Update package.json start script: "start": "npx electron-nightly ."
  3. Implement both session handlers in main.js:
    • session.defaultSession.setPermissionRequestHandler() - for initial requests
    • session.defaultSession.setPermissionCheckHandler() - for persistent permissions
  4. Run with npm start to test persistent permissions

This test case demonstrates the fix from PR #48170 working correctly in Electron nightly 40.x+
